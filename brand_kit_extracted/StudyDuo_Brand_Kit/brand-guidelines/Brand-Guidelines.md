# StudyDuo Brand Kit

## Brand idea
StudyDuo is a collaborative, gamified learning platform where two students learn, grow, and level up together. The paired owl mascots communicate companionship, curiosity, intelligence, and encouragement. Their shared open-book shape reinforces learning; the golden four-point star represents XP, achievement, and progress.

## Logo assets
- `logo/studyduo-owl-duo-master.png` — original square mascot artwork.
- `logo/studyduo-logo-square-1024.jpg` — high-quality square JPG.
- `app-icons/` — raster app icon exports from 16 px through 1024 px, plus a multi-size favicon ICO.
- `reference/studyduo-brand-board.png` — visual direction board.

## Color palette
| Name | HEX | Recommended use |
|---|---|---|
| Primary Purple | `#7651E8` | Primary brand, key actions, active states |
| Soft Lavender | `#A78BFA` | Secondary brand, highlights, supportive UI |
| Golden Accent | `#FFC857` | XP, achievement, progress, celebratory moments |
| Background | `#F8F5FF` | Main app and web backgrounds |
| White | `#FFFFFF` | Cards, contrast areas, mascot details |

## Typography
Recommended: **Plus Jakarta Sans**. Use 700 for headlines, 600 for buttons and navigation, and 400–500 for body copy. Inter or the system sans-serif stack are suitable fallbacks.

## Logo clear space and sizing
- Keep clear space around the icon at least equal to the height of one owl's eye.
- Use the 1024 px master for source/large placements; use the matching size export for app and browser use.
- Prefer 64 px or larger where the detailed mascot needs to read clearly. At tiny favicon sizes, test in the actual browser because fine facial details naturally simplify.
- Keep the artwork square and centered. Do not stretch, skew, crop the star, or add extra outlines.

## Backgrounds
- Preferred: `#F8F5FF` or white.
- For dense UI, place the icon on a clean, uncluttered surface with generous padding.
- Avoid busy photography, low-contrast gradients, and backgrounds that compete with the purple silhouette.

## Brand voice
Friendly, encouraging, clever, and collaborative. Celebrate small wins; use clear, positive language. Make progress feel achievable and shared.

## Suggested UI tokens
- Primary button: `#7651E8` with white label.
- Secondary surface: `#A78BFA` used sparingly.
- XP / achievement: `#FFC857` with dark-purple text or icon.
- Page background: `#F8F5FF`; card surface: `#FFFFFF`.

## Notes
This package contains raster logo exports and a visual direction board, not editable vector source files. For production, recreate the mascot as SVG/vector artwork before relying on it for large-format print or fully scalable use. The brand-board image is a visual reference; verify all small text and details before treating it as production artwork.
